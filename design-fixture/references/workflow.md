# Measured workflow router

Read [weld workflow](weld-workflow.md) only for welding, or [checking workflow](checking-workflow.md) only for checking. Both preserve exact source identity, datums, constraints, access and current evidence. Do not load the other mode's details.

The unified phase gate takes precedence over inherited end-to-end wording: survey, design, interactive preview, window-capture feedback/revisions, then stop. Build/export sections become active only after explicit package authorization (or an initial explicit complete-package request). Concept CAD is private evaluation, not a manufacturing release.
